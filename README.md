## Features

- UDP Flood  
  Overloading targets with UDP packets.

- HTTP Flood  
  Overloading web servers with HTTP requests.

## Requirements

- Python 3.x
- Stable Internet Connection

## Installation

```bash
pkg update && pkg upgrade
pkg install python
pkg install git
git clone https://github.com/teamicsf/ICSF-TOOLS
cd ICSF-TOOLS
python icsf-tools.py
```

## Usage

```bash
python icsf-tools.py
```
